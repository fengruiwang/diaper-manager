历史备份校验与恢复预览

仅在当前浏览器本地处理文件。 本页面的网络连接被安全策略禁止，不登录账号、不上传备份、不读取浏览器原有记账数据，也不执行真正的数据恢复。导入正式软件仍会替换当前数据，请不要在这里尝试恢复。

① 选择原有 v1.1.2 JSON 备份

先到当前正在使用的「小宝管家 → 数据备份与恢复 → 导出 JSON 备份」，得到一个备份文件；然后在此选择它。

② 重新选择下载后的保护副本

重新打开刚保存的保护副本，验证其校验值及原始备份是否可以一字不差恢复；不会把内容写回小宝管家。

③ 安全检查结果

等待选择文件。本页不会上传任何内容。

只报告状态和校验是否成功，不展示购买内容、品牌、金额、宝宝信息或校验文件原文。SHA-256 可检测意外修改，不是文件来源的数字签名。请妥善保管两个 JSON 文件，不要将它们发给开发对话或任何陌生网站。
