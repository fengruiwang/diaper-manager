# P1 浏览器登录冒烟测试页面

文件：cloudbase/smoke/auth-test.html

安全约束：
- 不引入 production index.html，不读写 diaper-manager 本地数据键。
- 用户在自己的浏览器输入 EnvId + 客户端 Publishable Key；不将密钥存入本页自建存储，绝不输入服务端 API Key。
- 发送 OTP、验证登录、查询 families 表最多一行（不显示行内容），不会创建家庭或上传纸尿裤数据。
- 临时测试页使用官方固定版本 CDN 3.0.1 便于无命令行测试；**这不代表 v1.2.0 生产版的 SDK 包装方式**。生产会固定版本并打包进 PWA，以支持 CloudBase 故障时本地离线启动。
- 因跨域白名单已启用 GitHub Pages，使用独立的 CloudBase 默认静态托管域名做临时测试时需先确认其域名在白名单中。默认自定义域名在用户控制台先前显示过。
- 在 CloudBase 控制台「静态网站托管 → 文件管理」中新建独立目录（如 \`xb-test\`），上传此 HTML 文件并使用官方提供的默认访问域名打开；不要覆盖站点根目录已有 index.html。
- 页面仅用于验证连接、邮箱 OTP、会话和读权限；真实家庭创建、邀请验证需要专门测试和服务端 RLS 负面验证。
- 测试完成后可以删除临时测试目录，不影响主站。
