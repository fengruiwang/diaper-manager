## 一次性申请阶段 B 授权的精确范围
在已安装 019/020 的同一 CloudBase 数据库和已有 A/B 家庭中，只允许如下业务写入：
1. 家庭 owner A 经 `public.xb_create_smoke_child(uuid)` 创建**最多一条** `legacy_slot='__xb_smoke_v1__'` 测试宝宝（服务器返回 child_id）；不可新建家庭、成员或第二个测试标识。
2. A 在该 child 下提交**一笔** S 码 +60 片；金额、品牌、系列采用 A 在原比价页实际填写的合法测试值，按分存储。
3. B 用已有 member 账号在**同一 child** 下提交**一笔** S 码 +80 片；金额、品牌、系列采用 B 在原比价页实际填写的合法测试值。
4. 允许针对上述**同一个** operation_id、同一 payload 做 ACK 丢失/网络重试及幂等核验，**不允许创造第三个采购操作**。允许只读库存、流水和身份权限刷新，以及不会触发后端业务写入的本地错误/权限拒绝测试。

**正常新增业务记录期望**：`xb_children` 1 行；`xb_transactions` 2 行；`xb_inventory_operations` 2 行；`xb_inventory` 为该宝宝的 S 尺码 1 行，数量 140、revision=2。其他五尺码由 010 只读 RPC 虚拟返回 0 和 revision=0，不会凭空新增五行。函数、平台审计和日志开销另计。

禁止事项：不执行其他 SQL DDL/DML、手动表 INSERT/UPDATE/DELETE，不停用测试宝宝、不清空数据、不调用 reverse/use/stocktake，不改 main/V1.1.2，不调整家庭权限、不迁移正式历史数据。

## 授权后最短操作流程（未授权前禁止部署/写入）
0. 只在**取得本轮阶段 B 明确授权后**，由用户将 Feature 的这 3 个文件覆盖/新增到现有独立托管路径 `xb-test/m1/`：`index.html`、`m1-controller.js`、`m102-cloud.js`。不要动静态站根目录、正式 PWA、GitHub Pages main。刷新浏览器确认页面出现“解锁本标签页阶段 B 写入”。三个文件采用**同一个 Git 提交**版本。
1. A 打开现有测试网址，使用之前通过的家庭账号登录；输入 `阶段B已正式授权`，点击解锁。点击“创建专用测试宝宝”，确认唯一标识，不再第二次创建。点击“进入隔离云端模式”，确认六尺码权威库存起点均为 0。
2. A 在原“好价比对”填 S、60 片、合法品牌系列和实付总价，点击“已购买 · 立即入库”**一次**，等到页面显示 `CLOUD_SYNCED` 且库存 S=60、流水 1 笔。
3. B 在另一设备/独立浏览器用已有 B 账号登录测试网址，输入相同授权短语并解锁；点击进入隔离云端模式，先确认 S=60。填 S、80 片与测试金额，点击入库**一次**，确认库存 S=140、流水 2 笔。
4. A 点击“刷新权威库存 / 采购流水”，确认 S=140、2 笔；B 刷新确认同样结果。刷新网页/重新进入后能读到相同结果，不要求再次创建宝宝。
5. 权限/异常最小验证：在 B 账号尝试创建测试宝宝应在客户端 owner 预检阶段被拒绝（**不向创建 RPC 发请求**）；重复点击同账号另一个新购会被拒绝；离线/未知 ACK 时只通过“原操作 ID 重试”处理，**不要再购买一次**。若要测试离线，优先把 A/B 两笔中某一笔作为离线入队场景，不能另开第三笔。
6. **不软停用**，保留记录供后续复核，直至用户单独确认测试结束。

## 停止条件
- 创建后看不到单条合法测试宝宝，或账号权限/家庭/child scope 有任何不确定：停止，不购买。
- 任意一端云端确认状态/流水/库存不一致：暂停，不发起新的购买；检查原操作 ID 状态与服务器现有记录。
- RPC 超时、权限错误、库存与流水不匹配、IDB 异常、页面报错、重复记录：停止新的业务写入；保留现场并反馈实际状态；不自动修数据库、不重建测试宝宝。
- 第一笔 S60 通过但第二笔失败：保留第一笔及测试宝宝，禁止通过清理重做来追求 S140；仅按原 ID 安全重试或单独评审。
- 测试宝宝软停用永久锁定该标识，故本轮不授权停用或删除测试历史。
