## 操作约束

1. 用户在正式 GitHub Pages PWA 首次登录一次，后续同源打开使用 SDK 持久会话。主动退出或令牌实际失效仍可能需要重新验证。
2. CloudBase 静态诊断站与 GitHub Pages 属于不同浏览器 origin，两处的登录状态无法自动共享。两手机也各有独立登录状态。
3. 正常启动先显示可用的本地快照，不能因云端临时故障反复弹验证码或阻断录入。
4. SDK 管理 refresh token，不复制到小宝管家 localStorage、IndexedDB 业务记录、URL、日志或公开 GitHub。
5. 保持登录不等于拥有家庭编辑权限：每次上传前仍须核对实时家庭成员与 xb app 权限。
6. IDB 的「verified-server」标签本身不是授权证明，可信来源核对需在后续云端读取和业务迁移流程中完成。
7. 所有正式 P2 SQL、真实旧版数据和腾讯云连接操作仍等待单独安全验收，本阶段不需要用户操作控制台。
